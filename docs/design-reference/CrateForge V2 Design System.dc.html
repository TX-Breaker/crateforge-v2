Same hierarchy, native manners. Identical structure, identical spacing — only the chrome strip and the control affordances change, so one layout serves both platforms.

Custom 34px title bar with app mark left, system controls right at the native 44px width; close turns destructive on hover. Radii drop to 6px, shadows tighten. Shortcut labels read Ctrl, not ⌘.

3.2  —  EXPERT MODE SIGNAL · TWO PROPOSALS

When experimental functions are unlocked the user must know it without looking for a badge. Both proposals are colour-plus-shape, so they survive colour-blindness and greyscale.

EXPERT MODE — EXPERIMENTAL FUNCTIONS UNLOCKED
EXPERT Enrich › Stems
Proposal A — Framed window

A hatched ochre strip across the top of the window plus a 1px frame. Impossible to miss, reads at any window size, and the hatch pattern carries the meaning without relying on hue. Costs 22px of vertical space permanently.

EXPERT MODE
EXPERT Enrich › Stems
Proposal B — Warmed sidebar · recommended

The whole navigation column shifts to a warmer, darker tone and gains a header chip; each experimental destination carries a dot marker. Persistent and unmistakable, but costs no layout space and never competes with a real warning.

Desaturated by design — eight cue colours that stay distinguishable in all six themes and in greyscale.
STRUCTURE

Intro, build, drop, breakdown and outro are tinted bands behind the envelope. This is the analysis result made legible — the DJ sees the shape of the track before reading a single number.

BEAT GRID

Two densities: a faint 4-bar rule and a stronger 32-bar phrase line. Phrase lines are what a DJ actually cues to, so they get the contrast.

MARKERS

Pointer capture, so the drag survives leaving the element. The flag inverts while dragging and the timecode updates live. Optional 1-bar snap.

NO PLAYBACK

A product decision, not a gap: listening happens in Rekordbox. Positioning here must feel precise, so the envelope is one path and re-renders cost nothing.

Rules of the component

Inner ring is minor (A), outer ring major (B). Clicking any segment re-centres the compatibility set: same number other ring, plus one step each way on the same ring.

The harmony logic is not reimplemented here — it comes from core/camelot.ts and core/harmony.ts, already covered by tests.

Hues follow the Mixed In Key convention DJs already read — 1 mint through 12 cyan, the minor ring a lighter tint of the same hue. Emphasis, not hue, carries the answer: selected and compatible segments are shown at full strength, everything else drops to a whisper of its colour.

Labels are always rendered, so compatibility never depends on colour alone. Segments are keyboard-reachable with roving tabindex and announce their key and relationship.

What an orphan is

An audio file that exists in a watched folder but is not referenced by any track in your library. Usually an old bounce, an unimported promo, or a file you removed from Rekordbox without deleting.

It is never automatically anything. CrateForge lists it and waits.

Quarantine, not delete

Files are moved to a folder inside your library, with a manifest recording where each one came from. Nothing leaves your disk.

Rules

The short list a reviewer can hold in their head. If a screen breaks one of these, the screen is wrong — not the rule.

Do
Use colour as information — state, severity, category — and never as decoration.
Pair every colour signal with an icon or a word, so nothing depends on hue alone.
Set numbers in tabular mono, always, so a counter never makes the layout jump.
State the destination of a write before and after it happens.
Show the declared limit inline and persistent; put only the outcome in a toast.
Give every empty state a reason and a way out.
Keep animation under 280ms and let prefers-reduced-motion switch all of it off.
Don't
No neon, no glow, no saturated gradients, no pulsing borders. Not in any theme, not on any element. This is a hard constraint, not a preference.
No colour without a label. The Camelot hues are the familiar ones, but every segment still prints its key and its musical name.
No decorative motion. If an animation does not explain a change of state, remove it.
No silent success and no silent failure. Everything lands in Activity.
No destructive action reachable from the command palette or a shortcut.
No hard-coded string. Four locales, key parity enforced by the test suite.
No remote asset. Fonts, icons and data are bundled — the renderer's CSP forbids the network.

LOCALISATION

Italian is the source language; English, French and German ship at parity, enforced by i18nParity.test.ts.

German runs the longest — every label in this system was checked against a +35% string growth. Nav items, badges and buttons truncate with a tooltip rather than wrapping.

Shortcut labels are platform-resolved at render: ⌘ on macOS, Ctrl on Windows, in every locale.

WHAT THIS DOCUMENT IS NOT

It is a design specification, not the application. The values here are meant to be lifted into tokens and Tailwind config; the components are meant to be rebuilt on the Radix primitives already in the project.

Nothing here changes the IPC contract, the safety gates, the sandboxing or the Python read engine. Where a design choice met a safety rule, the safety rule won — and the two places it happened are the command palette and the bulk bar, both noted above.
